# 裁决十：想法往前走了，算不算演变

**日期**：2026-10-27 00:40
**裁决人**：大乔（Lead）
**触发**：`B8q` 与内核规则对着干——模型正文在演进，内核永远存第一条

---

## 一、现象

同一个主题连喂四条，模型每轮输出的正文**确实在走**：

```
第1条 → 「他动手前总要问几遍这件事我还下不了结论」
第2条 → 「他动手前总要问几遍我算看明白了」
第3条 → 「他动手前总要问几遍就这么定下来」
第4条 → 「他动手前总要问几遍我改成按他的节奏来」
```

**但内核存下来的永远是第一条。** 因为它的规矩是：

> 同谓词、同立场的老判断：新证据推翻不了它，**改了说法也不该顺手换掉它原来的结论**。

---

## 二、这条规矩本来是对的，但它少了一个前提

那条规矩防的是**「流水账」**：

> 他心里记着「他问三遍」这件事，今天换成「他总是问三遍」，明天换成「他又问了三遍」——**这是同一个想法换着说法说，不该每次都改。**

**这个防护必须留着。** 不然她的判断会像水一样，被他每次说法不同带着走。

**但它漏了一种情况：说法变了，是因为想法真的往前走了。**

| | 例子 | 该不该改 |
|---|---|---|
| **换说法** | 「他问三遍」→「他总是问三遍」→「他又问了三遍」 | ❌ 不该 |
| **往前走** | 「我还下不了结论」→「我算看明白了」→「就这么定下来」→「我改成按他的节奏来」 | ✅ **该改** |

---

## 三、裁决

### 「想法往前走了」必须能改结论，但「换个说法」不许

**怎么分？看状态，不看字。**

内核已经有状态机了：

```
悬而未决（open）→ 想明白了（held）→ 曾经这么以为（retired）
```

**同一件事的结论，状态往前走了，就是往前走，要改。**

具体规矩：

```
同谓词、同立场，但【状态前进了一步】：
  open → held        → 结论必须换（第 2、3 条那种）
  held 有新深度       → 结论可以换（第 4 条那种）
  状态没动，只是措辞不同 → 不换（流水账，该防）

同谓词、同立场，状态也没动：
  → 一律不换，只加份量          ← 原来的规矩，保留
```

### 更要紧的一条：**内核不该只认「谓词+立场」这两个维度**

现在它判断「这是不是同一件事」，只看 `relation` + `polarity`。

**但「我还下不了结论」和「我算看明白了」——这两句的谓词和立场完全一样，可它们说的不是同一层。**

**所以判定「有没有变」，除了谓词和立场，还要看「这一句在说哪一层」：**

```
层级    表现
─────────────────────────────────────
悬置    「我还下不了结论」「次数太少」「看着像巧合」
看明白  「我算看明白了」「大概是……」「不是……是……」
定下来  「就这么定下来」「不问到他点头我不动手」
行动    「我改成按他的节奏来」「我先不动手」
```

**层级变了 = 想法往前走了 = 结论要换。**

---

## 四、怎么判「层级」（不靠猜句式）

**这个方法里有一处必须说清：不许用关键词表。**

（今晚刚从一个关键词表上吃过亏——主题归一那两层词表，陌生说法全落空。）

**那怎么判层级？**

**用模型自己给的信号。** 让模型在返回里多带一个字段：

```jsonc
{ "text": "...", "relation": "...", "polarity": 1,
  "stage": "pending|understood|settled|acting" }
```

- `stage` 是模型自己说的「我这一句说到哪了」
- 内核只做一件事：**比对这一条的 `stage` 和现役那条的 `stage`**
- **stage 前进 → 换结论**；stage 相同 → 不换

**这和「模型自认主题」（裁决二）是同一个道理：内核不猜，让她自己说。**

---

## 五、为什么这条要现在定

因为**它不只修 `B8q`**。它同时是：

| 受影响 | 为什么 |
|---|---|
| `B8q`（阶段不许原地不动） | 直接修 |
| 「会想多」的真义 | **它不是「同一句换说法」，是「同一件事想得更深」** |
| 落定（`settleReady`） | 状态前进和层级前进要一致，不能一个走一个不走 |
| 身份（`kind=identity`） | 一个人对自己的认识，本来就是一层层走上去的 |
