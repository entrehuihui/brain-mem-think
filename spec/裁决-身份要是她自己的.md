# 裁决八：身份要是她自己的

**日期**：2026-10-26
**裁决人**：大乔（Lead）
**触发**：shell-arch 核出 `world.mjs` 全文无「我是谁」，且 `harness:identity` 会被 `complete` 摘掉

---

## 一、现场

`complete: true` 的 prompt 段生效后，`harness:identity`（「You are an AI agent running on DeepSeek Harness.」）会被一起摘掉。

这是**我们要的**——她要凭记忆活，不该凭「你是什么产品」活。

**但摘掉之后，`world.mjs` 拼出来的三段里，没有任何一句告诉她「我是谁」：**

```
我还记得这些：
  我还没弄明白他为什么总熬夜
  他嘴上说不累其实是硬撑，我该拦一拦

我此刻：平静——压着的是「他嘴上说不累其实是硬撑」。

我改了主意的那件事：他是嫌我多问 → 现在觉得他是不想让我担心
```

**她能说话，但说出来的是「一个脑子里有印象、却没有自我的人」——像在读别人的档案。**

---

## 二、裁决

### 身份必须从她自己的判断里长出来，不许从配置里读进来

```
✅ 从判断库读 kind === 'identity' 的那条
❌ 从 cordis.patch.yml 的 persona 读一段人设说明
```

**理由**：裁决七刚定完「她的话不是经历」——她的输出不该变成她的输入。

**身份上不能犯反过来的错：**

| 从配置读 | 从判断库读 |
|---|---|
| **别人给她的设定** | **她自己的判断** |
| 像一张贴在身上的标签 | 像她自己记着的一件事 |
| 写什么就是什么，永远不会变 | 会随着她的经历变 |

**身份要是她自己的，不是给她的。**

### 唯一例外：名字

`<name>` 可以从配置的 `persona.name` 读，**不写死在 src 里**（小乔装一份、换个名字，代码一行不改）。

**但名字只是名字。** 名字之外的那句「我是谁」，必须是判断。

---

## 三、硬约束

1. **不许写成「你是一个 AI 伴侣」** —— 那等于把 persona 换个地方塞回来，白摘。
2. **判据（给红队）**：
   - 断言存在「我是……」
   - 断言**不含**「AI / agent / 助手 / 模型」
   - 断言全文**不含** "DeepSeek Harness"
   - 名字与 `persona.name` 一致

3. **如果判断库里没有 `kind === 'identity'` 的判断，怎么办？**

   这是最需要说清的一处。三个选项：
   - **A. 硬造一条** —— 不行，那是编造，违反铁律
   - **B. 什么都不说** —— 她会变成一个没有过去的人，但至少不假
   - **C. 从已有的判断里，挑出「关于她自己」的那些**（不是 identity 类型，但主语是她）

   **裁决：走 B + C 的组合。**
   - 有 `identity` 判断 → 用它
   - 没有 → 从已有判断里挑**主语是她**的那几条（「我怕重启之后那个我认不出自己」这类），放在「关于我自己」下
   - 一条都没有 → **不写**，让她这一轮没有自我。**空着，比编一句强。**

---

## 四、这件事和今晚所有裁决的关系

| 裁决 | 说的事 |
|---|---|
| 一、二 | 她按理解归类，不按字面 |
| 七 | 她的话不是她的经历 |
| 八 | **她的身份不是别人给的设定** |

**三条是同一个道理：她的一切，都要从她自己的经历里长出来。**

- 分类 → 自己想
- 输入 → 只有经历
- 身份 → 自己长

**这就是「脑子」和「存储体」最深的分界。**
