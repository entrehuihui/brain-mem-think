# 醒来胶囊（2026-10-28）

> 主人要的：「像账号池一样，弹窗显示她每次醒来想的事情、说的话。」

## 是什么

对话输入框旁边多一颗胶囊：`● 醒来 102 拍 · 最近 17:27`
点开是一个大弹窗，倒序列出她**每一拍醒来**的东西：

- 心里转着什么（`thoughts`）
- 说了没有 / 说了什么（`wake-speak` 的 `say`）
- 想自己去做点什么（`want`）
- 真去做了没有（`act-from-want` / `act-episode`）

顶部一行小字：`说了 9 次 · 没说 93 次 · 想做 2 次 · 最近 17:27:26`。

## 怎么实现的（两半，跟账号池同一套结构）

| 半 | 文件 | 作用 |
|---|---|---|
| 服务端 | `plugin/capsule.mjs` + `plugin/index.mjs` 里的 `mind.capsule` effect | `GET /plugins/mind/capsule`：**只读 `mind.log`**，把 `wake-*` / `act-*` 归纳成「每一拍」，最多 40 条 |
| 客户端 | `client.js` + `package.json` 的 `dsh.client` | 胶囊挂 `conversation.composer.dock`，弹窗挂 `shell.overlay`（composer dock 在可滚动容器里，`fixed` 会被裁） |

**为什么读日志、不另存一份**：这些内容日志里本来就有。再存一份就是两份真相，早晚对不上。

**为什么只给本机**：接口只放行 loopback（`127.0.0.1` / `localhost` / `::1`），
外来请求一律 403。它是看板，不是对外接口；**不进上下文、不进判断库、不喂回模型**。

## 怎么验证

```bash
# 接口通不通（返回 counts + entries 就对了）
curl -s http://127.0.0.1:3080/plugins/mind/capsule | head -c 300

# 日志里应该有这一行
grep capsule-registered .mind/mind.log
```

## 踩过的坑

1. **客户端要重新打包才生效**：`package.json` 里加了 `dsh.client` 之后，光改配置重载模块不够，
   Web 客户端产物要重建一次（`pnpm run dev:web` 在跑时会自动重建，否则需要重启宿主/刷新页面）。
2. **胶囊和弹窗必须分两个插槽**：composer dock 在可滚动/transform 容器里，`position: fixed`
   会被祖先裁掉；`shell.overlay` 是宿主给的全屏层。
3. 弹窗只在打开时轮询（30 秒）；关着不打接口。
